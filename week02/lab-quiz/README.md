

## Purchase Quote Program

This Python program calculates a purchase quote for two items.

### Features
- Gets two item names from the user.
- Gets the quantity and unit price for each item.
- Calculates the subtotal.
- Calculates tax based on the tax percentage.
- Adds the delivery fee.
- Displays the final total in TRY.

### Test Values
- Item 1: 2 × 50 TRY
- Item 2: 1 × 80 TRY
- Delivery fee: 20 TRY
- Tax: 10%

### Expected Result
The final total is **218.00 TRY**.
